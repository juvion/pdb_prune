简要总结如下：

对 utils/pdb_3dto2d_basepair2.py 的改进
- 引入并强制生物学配对规则（A-U、G-C、G-U），对不符合规则的配对进行拒绝并输出提示。
- 支持两种模式：all-atom 与 no-base-atom；统一使用 C4'-C4' 骨架距离判断，阈值约 13–17Å，并在可用时增加 N1/N9 距离约 7.5–10.5Å 的二次筛选。
- NPY 输入必须提供 FASTA 序列（--sequence），优先用 Biopython 读取，失败时自动使用内置简易解析器；DNA 序列会自动 T→U 归一化。
- 坐标读取更健壮：为 N1/N9 位置同时保存通用键（N1N9）与特定键（N1 或 N9），便于后续匹配。
- 集成配对报告功能：新增矩阵转对列表、dot-bracket 与配对列表导出函数；CLI 增加 --report {dot-bracket,list} 与 --report-file 选项，支持将二级结构或配对清单输出到文件。
- 保留最小序列间隔 min_separation=4（仅评分上三角），避免近邻不合理配对；PDB 解析自动将 D* 去氧核苷酸归一到 RNA，并将 T 转为 U。
- 主流程调整：process_structure 返回矩阵与序列；本地派生 residue_names/nums 以保障报告功能正常。

对 utils/sequence_similarity_score2.py 的改进
- Numba 可选加速，运行期若 JIT/类型转换失败，自动回退到纯 Python 实现，保证评分不因编译问题中断；确保传入矩阵为连续的 int8。
- 将 editdistance 与 Biopython 设为可选依赖：缺失时分别使用纯 Python Levenshtein 与内置简易 FASTA 解析器，避免 --help 或基础功能因模块未安装报错。
- 结构评分更合理：仅评分上三角、排除近邻（min_separation），使用预计算 4D 查表评分；当参考结构无配对时自动退化为纯序列评分。
- 支持两种序列相似度指标：编辑距离与恢复率（逐位准确率）；最终得分按 λ 加权组合（默认为结构占主，亦可切换到纯序列或纯结构）。
- 提升鲁棒性与训练友好性：直接字符串/数组输入，无文件 I/O；批量评分接口与详细统计输出更清晰。




#命令行
          
Here’s a consolidated cheat sheet of commands in this repo for data processing (generating base‑pair matrices, FASTA, NPY, PDB, and scoring). Replace paths/files as needed and run each tool’s --help for exact options.

Base‑pair matrix generation (2D)
- From a single PDB (with optional chain, report formats)
  - python utils/pdb_3dto2d_basepair2.py experiment/exp1/train/pdbs/1A9N_1_Q.pdb --output experiment/exp1/train/matrices/1A9N_1_Q.csv --mode all-atom --chain A --report dot-bracket --report-file experiment/exp1/train/matrices/1A9N_1_Q.db
  - python utils/pdb_3dto2d_basepair2.py experiment/exp1/train/pdbs/1A9N_1_Q.pdb --output experiment/exp1/train/matrices/1A9N_1_Q.npy --mode all-atom --chain A
- From a single NPY (sequence REQUIRED) with optional report
  - python utils/pdb_3dto2d_basepair2.py experiment/exp1/train/coords/1A9N_1_Q.npy --sequence experiment/exp1/train/seqs/1A9N_1_Q.fasta --output experiment/exp1/train/matrices/1A9N_1_Q.csv --mode no-base-atom --report list --report-file experiment/exp1/train/matrices/1A9N_1_Q_pairs.txt

PDB -> FASTA (extract sequence)
- Single file
  - python utils/pdb_to_fasta.py experiment/exp1/train/pdbs/1A9N_1_Q.pdb --chain A --output experiment/exp1/train/seqs/1A9N_1_Q.fasta
- Directory to FASTA folder (adjust options per --help)
  - python utils/pdb_to_fasta.py experiment/exp1/train/pdbs --outdir experiment/exp1/train/seqs

PDB -> NPY (extract 3D coordinates array)
- Single file
  - python utils/pdb_to_npy.py experiment/exp1/train/pdbs/1A9N_1_Q.pdb --chain A --output experiment/exp1/train/coords/1A9N_1_Q.npy
- Directory to NPY folder
  - python utils/pdb_to_npy.py experiment/exp1/train/pdbs --outdir experiment/exp1/train/coords

NPY/PDB utilities
- Reconstruct PDB from NPY + FASTA (choose one script available)
  - python utils/reconstruct_pdb.py --coords experiment/exp1/train/coords/1A9N_1_Q.npy --seq experiment/exp1/train/seqs/1A9N_1_Q.fasta --out experiment/exp1/train/pdbs/1A9N_1_Q_reconstructed.pdb
  - python archive/npy_to_pdb.py --coords experiment/exp1/train/coords/1A9N_1_Q.npy --seq experiment/exp1/train/seqs/1A9N_1_Q.fasta --out experiment/exp1/train/pdbs/1A9N_1_Q_reconstructed.pdb

Batch processing snippets (examples)
- Batch: PDBs -> matrices (.csv) + dot‑bracket reports
  - for f in experiment/exp1/train/pdbs/*.pdb; do base=$(basename "${f}" .pdb); python utils/pdb_3dto2d_basepair2.py "$f" --output "experiment/exp1/train/matrices/${base}.csv" --mode all-atom --report dot-bracket --report-file "experiment/exp1/train/matrices/${base}.db"; done
- Batch: PDBs -> FASTA + NPY + matrices
  - for f in experiment/exp1/train/pdbs/*.pdb; do base=$(basename "${f}" .pdb); python utils/pdb_to_fasta.py "$f" --output "experiment/exp1/train/seqs/${base}.fasta"; python utils/pdb_to_npy.py "$f" --output "experiment/exp1/train/coords/${base}.npy"; python utils/pdb_3dto2d_basepair2.py "$f" --output "experiment/exp1/train/matrices/${base}.csv" --mode all-atom; done
- Batch: NPY + FASTA -> matrices
  - for f in experiment/exp1/train/coords/*.npy; do base=$(basename "${f}" .npy); python utils/pdb_3dto2d_basepair2.py "$f" --sequence "experiment/exp1/train/seqs/${base}.fasta" --output "experiment/exp1/train/matrices/${base}.csv" --mode no-base-atom; done

  - python utils/sequence_similarity_score2.py --pred-seq "AUGCUA..." --ref-seq "AUGCUA..." --ref-matrix experiment/exp1/train/matrices/1A9N_1_Q.npy --lambda 0.5 --seq-score-type edit_distance --no-numba

  - python utils/pdb_to_fasta.py --help
  - python utils/pdb_to_npy.py --help
  - python utils/reconstruct_pdb.py --help
