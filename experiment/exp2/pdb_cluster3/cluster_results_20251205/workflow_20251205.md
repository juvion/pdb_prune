**Workflow Summary**
- Extract single RNA chains from PDBs, filter by length, and save per-chain PDBs.
- Derive nucleotide sequences from those chains to FASTA for QC or optional sequence clustering.
- Compute the pairwise TM-score similarity matrix using `USalign` in RNA mode.
- Convert similarity to distance and run agglomerative clustering; save assignments, distributions, dendrogram, and threshold comparison.

**Prerequisites**
- `USalign` available at `/Users/xiaojuzhang/rna_tools/USalign` (RNA mode).
- Python environment with `biopython`, `numpy`, `pandas`, `scipy`, `matplotlib`, `tqdm`.
- Input directory containing original PDB files.

  - `--verbose`: Logs exact `USalign` calls and parsing diagnostics.
- Outputs:

**Step 4: Agglomerative Clustering**
- Script: `experiment/exp2/pdb_cluster3/utils/agglomerative_clustering.py`
- Purpose: Convert similarity to distance (`1 - TM`) and cluster with hierarchical linkage; save clusters and plots.
- Command:
  - `python /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/utils/agglomerative_clustering.py --input /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/cluster_results/tm_score_matrix.csv --thresholds 0.6 0.5 0.4 --method average --output_prefix /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/cluster_results/validation/structure_clusters --plot`
  > `python /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/utils/agglomerative_clustering.py --input /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/cluster_results/test/tm_score_matrix_test_20251205.csv --thresholds 0.6 0.5 0.4 --method average --output_prefix /Users/xiaojuzhang/Dev/pdb_prune/experiment/exp2/pdb_cluster3/cluster_results/test/structure_clusters --plot`
- Behavior:
  - Transforms `S` to distance `D = 1 - S`, ensures diagonal 0, and runs `scipy` linkage (default `average`).
  - Cuts tree at distance `1 - threshold` to produce cluster labels.
- Outputs:
  - Assignments: `.../structure_clusters_0.6.csv`, `.../structure_clusters_0.5.csv`, `.../structure_clusters_0.4.csv`
  - Distributions: `.../structure_clusters_0.6_distribution.csv` (exists at the path you showed), etc.
  - Dendrogram: `.../structure_clusters_dendrogram.png`
  - Size distribution plot: `.../structure_clusters_size_distribution.png`
  - Threshold comparison: `.../structure_clusters_comparison.csv` (cluster counts and size stats across cutoffs)

**Quality Checks and Tips**
- USalign mode: Always use `--mol RNA`; your build expects string modes.
- Binary path: Prefer `--usalign_bin /Users/xiaojuzhang/rna_tools/USalign` to avoid PATH issues.
- Sanity check: Spot-run `USalign <A.pdb> <B.pdb> -mol RNA` and confirm `TM-score=` in output.
- Thresholds: Start with `0.6/0.5/0.4`; higher thresholds yield fewer, purer clusters.
- Scaling: Remove `--limit` and use checkpointing in long runs; tune `--timeout` for stability.
- Validation: Inspect `tm_score_matrix.csv` stats; expect non-zero off-diagonals and diagonal ones.
- Output placement: Choose `--output_prefix` to control where cluster CSVs and distributions land (e.g., `cluster_results/validation`).

This gives you an end-to-end, reproducible path: chain extraction → FASTA → TM matrix → hierarchical clustering, with clear inputs/outputs and parameters suitable for RNA structural datasets.
