RNA PDB Files Collection

This directory contains RNA structure files downloaded from the Protein Data Bank (PDB) based on the testing output list.

Source Information:
- All PDB files were downloaded from the official Protein Data Bank (PDB)
- Files were selected based on the testing output criteria
- Only RNA structures are included in this collection

File Format:
- Files are in standard PDB format
- Each file represents a complete RNA structure
- Original PDB IDs are preserved in the filenames

Purpose:
This collection serves as the source dataset for RNA structure analysis and processing, particularly for:
- RNA loop extraction
- RNA segment analysis
- Structure-based studies

Processed Files:
- The processed_pdbs directory contains single-stranded RNA segments extracted from the PDB files in the root folder
- These extracted segments are derived from the original complete structures
- Each processed file represents a single continuous RNA strand

Note: These files are used as input for the RNA extraction and analysis pipeline.
